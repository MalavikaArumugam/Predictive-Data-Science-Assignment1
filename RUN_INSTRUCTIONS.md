# Run Instructions

## Python in VS Code
Open this folder in VS Code. Use **Terminal → New Terminal** from the project root:

```bash
python python/simple_linear_regression.py
python python/logistic_regression.py
python python/decision_tree_classifier.py
python python/svm_classifier.py
python python/naive_bayes.py
python python/market_basket_analysis.py
```

No third-party Python packages are required.

## R in RStudio
Set the working directory to this project root and run:

```r
source("r_programs/breast_cancer_prediction.R")
source("r_programs/hr_demand_prediction.R")
```

The R scripts use base R.
